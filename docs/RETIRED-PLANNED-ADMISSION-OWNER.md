# Retired Lane Compatibility

Legacy planned-owner retirement is superseded. An ADLC lane becomes retired
only after an accepted integration proof and exact clean worktree retirement.
An abandoned or dirty lane is preserved until its owner makes a separate
decision. See `CANONICAL-LIFECYCLE.md`.
